# MIQNAAS × AZZDAN — Interactive Proposal

Arabic RTL, mobile responsive, static proposal site for GitHub Pages. No backend or database; all quote selections and notes stay on the visitor's device.

## GitHub Pages

1. Create a new GitHub repository (preferably private until approval; public GitHub Pages deployment generally exposes the published content).
2. Upload **`index.html`** and the full **`assets/`** directory to repository root (or upload all files from this archive).
3. Go to **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)` and save.
4. Open the URL GitHub provides and test toggles, mobile navigation, copy and printing.

## Customer flow

Select optional identity and/or packaging → enter name, status, feedback → choose **إصدار ملخص عرضي PDF** → browser print dialog → **Save as PDF** → manually send to MIQNAAS. `window.print()` requires a normal browser; it does not create an invoice, store customer data, or send an email. PDF contains full scope and selected add-ons.

## Assets
- `assets/miqnaas-logo-color.png`, `assets/miqnaas-logo-light.png`: real MIQNAAS emblem/wordmark derived from customer-provided brand guideline PDF.
- `assets/azdan-logo.jpg`: supplied AZZDAN logo image.
- Text uses IBM Plex Sans Arabic and Manrope through Google Fonts with fallbacks; if offline the fallback font is used.

- Finalize eligibility/expiration/repeatability terms for future 25% discount and state them in the signed commercial offer.
- Enter the correct contact/submission channel if you want a direct WhatsApp/email button; none is guessed here.
